How it works

Three steps to a
production-ready workspace.

STEP 01
🔑
Connect your accounts
Paste your Groq API key (free) and Notion integration token. Share a parent page with the integration. That's all the setup required.
groq.com/console → Free API key
notion.so/my-integrations → Token
STEP 02
✍️
Describe your workspace
Type what you want in plain English. Be specific — mention databases, linked views, formula types, or use one of the built-in prompt chips.
"Build a freelancer CRM with
clients → projects → invoices,
formula for total revenue…"
STEP 03
⚡
Watch it build live
Notionify AI calls the Notion API in real time. Watch each database, relation, and page get created in your live workspace. Done in under 60 seconds.
Databases → Relations → Pages
→ Sample rows → Done ✓
STEP 04
🎯
Open and start using it
Click the link in the builder — your workspace opens in Notion, fully structured, with covers, sample data, and all properties wired up.
↗ Open in Notion → Ready to use
